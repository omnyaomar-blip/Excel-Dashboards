# Excel-Dashboards
Simple Excel Dashboards
**project 1**
Developed an interactive sales dashboard in Excel using Pivot Tables, Power Query, and Slicers.
- Built measures and calculated fields to analyze sales performance across regions, managers, and products.
- Designed a clean and dynamic interface to track KPIs and support decision-making.
- enhanced data cleaning and transformation with power query for accurate reporting

  **project 2**
The challenge here was to bring together HR and Finance data into a single, interactive view:

- KPI cards for Total Expenses split into Salary, Bonus, and Overtime.
- Employee breakdown by gender, contract type (full-time vs part-time), and activity status (active vs inactive).
- Expenses by Department with clear ranking.
- Average Salary comparison with a combo box to switch between By Age and By Experience.
- Department Headcount analysis and a performance rate chart to highlight areas needing improvement.
- Fully interactive navigation with slicers for department-level insights.

 *The result: An HR Dashboard that provides management with a clear, actionable view of workforce distribution, costs, and performance — all in one place.

 **project 3**
 Built 4 combo boxes to switch dynamically between:
KPI (Sales / Quantity / Profit)
Territories 
Current year vs. Previous year
Product categories
- Added a scroll bar to browse products directly from the selected category.
- Designed two column charts:
One for months
One for products (fully dynamic, with no empty spaces thanks to the OFFSET function).
